# Ollama для Windows — Установка и Обновление

Комплект скриптов для развёртывания и обновления [Ollama](https://ollama.com) на Windows в виде службы через [NSSM](https://nssm.cc). Скрипт автоматически проверяет наличие установленной версии и предлагает интерактивное меню для обновления. Оптимизирован под **NVIDIA RTX 4060 (8 ГБ VRAM)**.

## Состав комплекта

| Файл | Назначение |
|---|---|
| `ollama-windows-install.ini` | Единый конфиг (пути, сеть, модели, производительность) |
| `ollama-windows-install.ps1` | Установка / Обновление (с бэкапом и пересозданием службы) |
| `ollama-windows-uninstall.ps1` | Удаление службы и очистка |

## Основные изменения

1. **Папки `Downloads` и `Backup`**: Все дистрибутивы сохраняются в `Downloads`, а при обновлении текущая версия упаковывается в `Backup\Ollama_YYYYMMDD_HHMMSS`.
2. **Функция обновления встроена в установку**: При запуске `ollama-windows-install.ps1` скрипт проверяет текущую версию, исключает её из списка выбора и, если выбрана новая, делает бэкап, удаляет службу и устанавливает новую.
3. **Описание службы**: Автоматически прописывается `Ollama is the most popular way to build with open models...`.
4. **Очистка `OllamaTM.exe`**: Перед обновлением/удалением скрипт принудительно завершает процесс `OllamaTM`, чтобы избежать блокировки файлов.
5. **Исправление прав (SID)**: Используется `*S-1-5-18` и `*S-1-5-32-544` для `icacls`, что гарантирует работу на любой локализации Windows (включая русскую).

## Быстрый старт

1. Отредактируйте `ollama-windows-install.ini` (проверьте `FirewallSubnet`).
2. Запустите `.\ollama-windows-install.ps1`.
3. Если Ollama уже установлена, вы увидите текущую версию и список доступных для обновления.
4. Выберите нужную версию (текущая исключена из списка).

## Удаление

```powershell
# Удалить службу, сохранив модели и бэкапы
.\ollama-windows-uninstall.ps1

# Полная очистка (включая модели, бэкапы и архивы)
.\ollama-windows-uninstall.ps1 -PurgeProfile -PurgeModels -PurgeOllama -PurgeLogs -PurgeDownloads -PurgeBackup -Force
