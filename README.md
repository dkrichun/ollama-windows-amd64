# Ollama для Windows — Установка, Обновление и Удаление

Комплект скриптов для развёртывания и обслуживания [Ollama](https://ollama.com) на Windows в виде службы через [NSSM](https://nssm.cc). Оптимизирован под **NVIDIA RTX 4060 (8 ГБ VRAM)**.

## Состав комплекта

| Файл | Назначение |
|---|---|
| `ollama-windows-install.ini` | Единый конфиг (пути, сеть, модели, производительность) |
| `ollama-windows-install.ps1` | Установка, обновление и переустановка службы |
| `ollama-windows-uninstall.ps1` | Удаление службы и очистка |
| `README.md` | Этот файл |

## Основные возможности

1. **Папки `Downloads` и `Backup`**: 
   * Дистрибутивы сохраняются в `Downloads\ollama_<версия>\` и `Downloads\nssm_<версия>\`, что позволяет хранить архивы разных версий одновременно.
   * Резервные копии при обновлении/переустановке сохраняются в `Backup\Ollama_YYYYMMDD_HHMMSS`.
2. **Умное обновление и переустановка**: 
   * Скрипт определяет текущую версию и показывает меню со всеми стабильными релизами.
   * Текущая версия **помечена** как `(переустановка)` — вы можете выбрать её для полной переустановки (например, если файлы повреждены).
   * **Выбор версии и подтверждение происходят в самом начале** — до остановки службы и создания бэкапов. Если вы нажмёте `s` в меню, служба продолжит работать без изменений.
3. **План действий**: перед началом работы скрипт показывает сводку (текущая версия → целевая, режим, нужен ли бэкап) и просит финальное подтверждение.
4. **Описание службы**: автоматически прописывается официальное описание Ollama.
5. **Очистка `OllamaTM.exe`**: перед обновлением/удалением скрипт принудительно завершает процесс `OllamaTM`, чтобы избежать ошибки "Access denied".
6. **Безопасные права (SID)**: используется `*S-1-5-18` и `*S-1-5-32-544` для `icacls`, что гарантирует работу на любой локализации Windows (включая русскую).
7. **Диагностика**: при невозможности запустить службу скрипт выводит логи NSSM и пробует запустить `ollama.exe serve` напрямую, чтобы показать причину.

## Быстрый старт

1. Отредактируйте `ollama-windows-install.ini` (проверьте `FirewallSubnet` и пути).
2. Запустите `.\ollama-windows-install.ps1`.
3. Если Ollama уже установлена:
   * Вы увидите текущую версию.
   * Меню покажет список стабильных версий с пометкой `(переустановка)` на текущей.
   * Нажмите **`s`**, чтобы отменить — служба не будет остановлена.
   * Или выберите нужную версию (новую для обновления, текущую для переустановки).
4. Скрипт покажет «План действий» и спросит финальное `Продолжить? [Y/n]`.
5. Дождитесь завершения установки и проверки API.

## Удаление

```powershell
# Удалить службу, сохранив модели, бэкапы и архивы
.\ollama-windows-uninstall.ps1

# Полная очистка (включая все модели, архивы и бэкапы)
.\ollama-windows-uninstall.ps1 -PurgeProfile -PurgeModels -PurgeOllama -PurgeLogs -PurgeDownloads -PurgeBackup -Force -NoPause
